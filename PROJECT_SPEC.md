
# Project Specification

## Project Name
Project Registry

## Project Objective
Build a decentralised application that allows
users to register, view and manage projects
using blockchain technology.

## Target Users
Anyone with an EVM-compatible crypto wallet.

## Core Features
1. Connect crypto wallet.
2. Register a project.
3. View registered projects.
4. Update project details.
5. Transfer project ownership.

## Blockchain
Ethereum-compatible testnet.

## Smart Contract
Solidity.

## Frontend
React and TypeScript.

## Wallet
MetaMask.

## Development Framework
Foundry.

## Security Requirements
- Only project owners can update their projects.
- Only project owners can transfer ownership.
- Validate user inputs.
- Never expose private keys.
- Test successful and unsuccessful transactions.

## Initial Release
A working dApp deployed on a public testnet.
